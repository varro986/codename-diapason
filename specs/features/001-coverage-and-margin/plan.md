# 001. Coverage and margin: plan

## Components

```
Diapason.slnx
|-- src/
|   |-- Diapason.Domain/      types of the data contract, costing, economics, checks; no I/O
|   |-- Diapason.Workbooks/   reader, template and sample writers, folder loader
|   |-- Diapason.Web/         ASP.NET Core + Blazor on localhost: options, loaded state, page, it/en resources
|   \-- Diapason.Tool/        command line: `templates <folder>`, `sample-data <folder>`
|-- tests/
|   |-- Diapason.Domain.Tests/
|   |-- Diapason.Workbooks.Tests/
|   \-- Diapason.Web.Tests/
|-- tools/                    new-templates.ps1, new-sample-data.ps1
\-- cicd/                     run.ps1: build with warnings as errors, format check, tests
```

Flow: `DataFolderLoader` lists the folder, `WorkbookReader` turns each workbook into domain types plus the issues of
its cells, the domain checks references and rules, costs every assignment fortnight by fortnight and sums the
economics. The web app holds the last `LoadResult` and replaces it on "Reload".

## Contracts

- `Diapason.Domain`: `Registry`, `Plan`, `Assignment` and the other types of the data contract; `Issue` (severity,
  code, location: workbook, sheet, row, column; arguments), localised only by the UI; `CostRow` per assignment and
  fortnight; `Economics` per area, engagement and total, per `Kind`.
- `Diapason.Domain.DataContract`: the only place with sheet and column names, in the domain because its checks name
  the column to fix; reader and writers both use it, and a round-trip test (write a sample, read it back) keeps them
  aligned.
- Configuration (`appsettings.json`, section `Diapason`): `DataFolder` (overridden by `DIAPASON_DATA_FOLDER`),
  `RegistryFileName` (`registry.xlsx`), `HoursPerDay` (8).

## Risks

- ClosedXML reads cached values of formulas: a workbook saved by Excel has them; one generated by a tool without
  Excel may not. Countermeasure: sample data writes values, not formulas.
- Excel keeps a workbook locked while open: the reader opens files read-only with shared access, and a file that
  cannot be read is an issue, not a crash.
